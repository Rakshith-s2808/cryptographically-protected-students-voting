SECURITY BY DESIGN

Five locks. One fair vote.

Each lock addresses a different security requirement.

01
IDENTITY

Login

Check student eligibility and protect stored passwords.

PBKDF2 · SHA-256
02
ELIGIBILITY

Pass

Use a one-time voting pass designed to separate identity from ballot.

RSA blind signatures
03
CONFIDENTIALITY

Seal

Encrypt the ballot before it reaches the server.

AES-GCM · RSA-OAEP
04
INTEGRITY

Chain

Link ballot records so unauthorized changes can be detected.

SHA-256 hash chain
05
VERIFICATION

Receipt

Check whether your ballot appears in the published records.
